# a36 from the a34 baseline

This release continues a34 application and storage contracts. It adds B/BL
listing-time author statistics, compact nonzero summaries, an instant B-Class
switch without an Apply button, hourly main-page highlights, one-second server
resource updates and the newsletter anniversary-cache repair.
Compatible responsive styles are retained. The earlier a35 runtime,
Archive/control and Starlette redesign is excluded.

The last successful newsletter capture before repair was
`2026-11-10T00:00:05+00:00`. Refreshes failed because the configured
`cache/today-in-history` path was a directory of timestamped Parquet files,
while the anniversary reader required a regular file. The reader now accepts
both cache-owner contracts and reuses existing source revisions.

B/BL attribution uses the first revision of the latest continuous literal
project-banner range. A bounded Replica query selects the article revision at
or before that assessment timestamp; the article revision's timestamp supplies
the displayed B-Class date. Parquet retains the subject page ID, last checked
talk head, assessed talk revision and time, nearby article revision and time,
resumable progress and attribution evidence. Article-only edits reuse all of
these facts. A newer talk head reads only its new revisions in bounded batches;
continuous B/BL ranges retain their original assessment and article cutoff.
Demotion and re-entry start a new range. Parser or talk identity changes require
fresh proof; inaccessible history remains pending.

About server resources are sampled into one small current file each second and
streamed to the browser. Execution history keeps its existing slower heartbeat.
The read-only website accepts only fresh samples from the selected hub boot.

The superseded a35 candidate was safely drained and the original a34 source
restored on November 12 at 13:01:24 UTC. November 13 verification reconfirmed
that source and one available hub/web replica before preparing this release.
Prior source generations, environments and recovery artifacts remain retained.

Offline verification passed 1,542 unit tests, 774 Toolforge-facing tests,
16 integration tests, 77 JavaScript tests, locked dependencies, Ruff and source
payload checks. Chromium passed 882 responsive page cases and 72 cases without
JavaScript across all three locales. Switch cases covered fragment replacement,
rapid changes, failed requests, focus retention and locale-link state.
