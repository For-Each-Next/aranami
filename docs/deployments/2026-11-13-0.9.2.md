# Version 0.9.2 final source release

Version 0.9.2 consolidates all unpublished development after v0.8.8 into one
commit, preserving v0.8.8 and earlier history. The final source repository is
[aranami-old](https://github.com/For-Each-Next/aranami-old), archived after
successful release verification. Toolforge continues independently with its
saved reports, Parquet caches, credentials and scheduled background work.

The [0.9.1 deployment record](2026-11-13-0.9.1.md) describes the quality-analysis,
English summary and manual consistency-review behavior. This final deployment
places **Edit and view changes** beside **Copy wikitext**. Its userscript installs
from `/consistency-repair.user.js`, checks the exact talk-page source and draft,
fills the complete prepared section zero and summary, then invokes only Diff.

## Snapshot capacity correction

would have increased its normal JSON representation to 9,153,998 bytes, causing
repeated safe write failures and preserving an older snapshot. Compact JSON
reduces the current core to 8,027,402 bytes. The writer now admits only complete
source/proposal pairs within the remaining eight MiB capacity and removes links
for unavailable proposals. The separate Parquet cache retains all 256 inputs;
no findings or source evidence are discarded. The first successful refresh
completed at `2026-11-13 16:59:33 UTC`; a later saved snapshot contained 80
ready complete proposals within 8,384,993 bytes. The public saved-repair API
returned HTTP 200 with the complete replacement, summary and source guards.

Independent checks exercised Unicode headers, repeated finding references,
capacity boundaries, detached source inputs and complete schema validation.
The byte limit and atomic replacement behavior remain intact.
