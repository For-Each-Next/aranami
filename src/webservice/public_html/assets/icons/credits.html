Content icon credits

These icons identify main-page highlights, popularity ranks, and content reviews. Highlight icons represent saved featured, good, or did-you-know appearances independently of current assessments. The highlight, candidate, and community peer-review SVGs are unchanged Commons files; the project peer-review SVG is a vector redraw of its Commons PNG source. Each image retains its own license.

The review selections follow the Chinese Wikipedia review module. The maintenance overview has separate image credits and template correspondence.

Complete GNU license texts: LGPL version 2.1 and GPL version 2. The affected icons permit the stated version or any later version. The interface stylesheet has a separate Codex license notice.
