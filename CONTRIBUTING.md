# Contributing to Aranami

Aranami is developed, tested, and built as a wheel on a development computer.
Read the [design and development guide](docs/development.md) for architecture,
report contracts, engineering conventions, verification, and releases.
Repository and package-specific instructions are in [AGENTS.md](AGENTS.md).

See the [documentation index](docs/README.md) for installation, configuration,
and API guides.
