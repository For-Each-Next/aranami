# Contributing to Aranami

Aranami is developed and tested locally with Python 3.15, then deployed
from source to Toolforge. Run the offline checks in the
[verification guide](docs/development.md#verification-and-releases) before
preparing an upload. Use a recent uv release that supports Python 3.15.

Use the [application development guide](docs/development.md) for practical
contribution, testing, and release work. Read the
[system architecture guide](docs/architecture.md) when changing component
boundaries or shared contracts; it is also the system-level guide for AI
coding agents. Repository and package-specific instructions are in
[AGENTS.md](AGENTS.md).

The [usage guide](docs/usage.md) covers terminal inspection, immediate
reports, previews, and managed report settings. The
[administration guide](docs/administration.md) covers source uploads,
Toolforge process management, runtime folders, and recovery. Documentation
is maintained in English; the website supports three interface languages.
